# ConvertFrom-DataTable

## SYNOPSIS

Converts System.Data.DataTable or System.Data.DataRow objects into PSObjects.

## SYNTAX

### Table
```
ConvertFrom-DataTable [-Table] <DataTable[]> [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

### Row
```
ConvertFrom-DataTable [-Row] <DataRow[]> [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

ConvertFrom-DataTable converts ADO.NET DataTable or DataRow objects into PSObjects that work naturally in the PowerShell pipeline. Each DataRow becomes a PSObject with a PSNoteProperty for every column in the table. DBNull values are converted to $null.

This cmdlet is useful when working with ADO.NET query results, SqlDataAdapter output, or any .NET code that returns DataTable objects. It lets you take typed relational data and pass it to standard PowerShell cmdlets such as Where-Object, Select-Object, and Format-Table.

Use -Table when you have a whole DataTable and want all of its rows converted. Use -Row when you already have individual DataRow objects, such as those obtained by indexing into DataTable.Rows. Both parameters accept pipeline input, and PowerShell automatically selects the correct parameter set based on the type of the object being piped.

## EXAMPLES

### Example 1: Convert a DataTable returned by a SQL query

```powershell
$connection = New-Object System.Data.SqlClient.SqlConnection 'Server=.\SQLEXPRESS;Database=MyDb;Integrated Security=True'
$adapter    = New-Object System.Data.SqlClient.SqlDataAdapter 'SELECT * FROM Employees', $connection
$dataTable  = New-Object System.Data.DataTable
$adapter.Fill($dataTable)

$dataTable | ConvertFrom-DataTable
```

Pipes a DataTable returned by a SqlDataAdapter into ConvertFrom-DataTable. Each row in the table is emitted as a PSObject with properties matching the column names.


### Example 2: Convert individual DataRows from DataTable.Rows

```powershell
$dataTable.Rows | ConvertFrom-DataTable
```

Pipes the DataRowCollection from a DataTable's Rows property directly into ConvertFrom-DataTable. Each DataRow is converted to a PSObject independently.


### Example 3: Create a DataTable in PowerShell and convert it

```powershell
$table = New-Object System.Data.DataTable
$null  = $table.Columns.Add('Id',   [int])
$null  = $table.Columns.Add('Name', [string])
$null  = $table.Columns.Add('Score', [double])

$null = $table.Rows.Add(1, 'Alice', 98.5)
$null = $table.Rows.Add(2, 'Bob',   [System.DBNull]::Value)
$null = $table.Rows.Add(3, 'Carol', 74.0)

$table | ConvertFrom-DataTable | Where-Object { $_.Score -ne $null }
```

Creates a DataTable with three columns, adds rows (including one with a DBNull value), converts the table to PSObjects, and filters out the row where Score is $null. The DBNull in Bob's Score column becomes $null on the resulting PSObject.

## NOTES

- DBNull column values are converted to $null on the output PSObject.
- Each DataRow becomes exactly one PSObject. Properties appear in column definition order.
- When piping, PowerShell selects the -Table or -Row parameter set automatically based on the type of object received. You do not need to specify the parameter name.
- Column names are used as property names exactly as defined in the DataTable. Names with spaces or special characters will produce PSNoteProperty names that require quoting when accessed (e.g., `$obj.'First Name'`).
